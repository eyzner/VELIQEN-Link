# Проверка VELIQEN Link 1.2.0

Дата: 21 ноября 2026 года.

## Результат

Собран подписанный APK 1.2.0. Настольное приложение проверено настоящими GTK-виджетами в изолированном X11-сеансе, Android-приложение — в программном AOSP-эмуляторе API 23. Автоматизированные наборы настольной части и KDE backend: **189 тестов, все прошли, без пропусков**. Дополнительно прошли проверки установщика Ubuntu, интегратора ROM и сценарии отображения интерфейса.

Проверки не использовали телефон и ноутбук пользователя. Сотовые звонки, звук в обе стороны, физический Bluetooth и MediaProjection на целевом Android 17 здесь не испытывались.

## Установщик Ubuntu

Сохранено исправление недоступного зеркала из предыдущего обновления. Режим `--ubuntu-main-mirror` создаёт временные официальные HTTPS-источники с текущими suites, components, архитектурой и Signed-By. Постоянные источники и обычные списки APT не переписываются, проверка подписей не отключается.

Изолированный harness для версии 1.2 проверил:

- update → download-only → корректное завершение прежнего приложения → install с тем же кэшем → завершающие действия;
- одинаковые временные источники, списки и кэш во всех фазах;
- приложение не закрывается при ошибке обновления или скачивания;
- при ошибке завершения установка не начинается, при ошибке установки финализаторы не запускаются;
- сохранение `.list`/`.sources`, включая встроенный ключ, отказ для не-Ubuntu, смешанных источников и небезопасных настроек доверия;
- доступный для `_apt` путь локального пакета и справку без установки.

Настоящие sudo/APT, системные службы и файлы тест не менял. Доступность зеркал с компьютера пользователя этим не проверяется. Shell-синтаксис установщиков проверен.

### Исправление локальной установки APT после выпуска 1.2

Пользовательский запуск выявил ошибку `Internal Error, Pathname to install is not absolute` в финальном вызове APT с `--no-download`. Прежняя проверка порядка действий использовала заглушку APT и не моделировала его обработку локальных пакетов; она не могла обнаружить этот дефект.

Флаг удалён из финальной команды. Предварительный `--download-only`, запрет удаления пакетов `--no-remove`, временные источники и общий кэш сохранены. Конечная обработка локального пакета выполняется обычной командой `apt-get install`.

Добавлен `tests/check_installer_local_apt.py`, проверенный настоящим APT 3.0.3 в полностью временном окружении. Старая команда воспроизвела точный текст ошибки даже с абсолютным аргументом. Исправленная команда передала абсолютный путь в защитный обработчик dpkg. Зависимость из тестового репозитория на `127.0.0.1` была скачана ровно один раз и повторно использована из кэша.

Защитный обработчик намеренно возвращает ошибку 42 перед любой установкой; настоящий dpkg не устанавливает, не распаковывает и не настраивает пакеты. Системные источники, база пакетов и службы не меняются, sudo не используется. Это проверка маршрута APT, а не реальная установка на Ubuntu пользователя. Журнал: `docs/qa/local-apt-check.txt`.

APK, `.deb` и ROM payload остались побайтово прежними. Исправлены установщик, его проверки и документация полного архива.

## Что проверить на своих устройствах

1. Обновление обеих сторон без удаления приложения и сохранение сопряжения.
2. Передачу файла, ручной буфер, разрешения SMS и одну отправку сообщения.
3. Цифровой набор, входящий вызов, слышимость в обе стороны и цифры в голосовом меню.
4. Показ экрана с подтверждением Android, остановку и повторный запуск; отдельно — разрешённое управление мышью.
5. Сон, потерю Wi-Fi/Bluetooth и повторное подключение.

Нативный экран по-прежнему ограничен 8 кадрами в секунду и не передаёт звук медиа. Сотовый звук использует Bluetooth HFP. Автоматический буфер GNOME/Wayland и платформенное разрешение фонового буфера Android проверяются в соответствующих пользовательском сеансе и прошивке.
