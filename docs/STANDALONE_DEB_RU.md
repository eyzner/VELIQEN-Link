# Установка VELIQEN Link 1.2.1 в Ubuntu

Основной файл: `veliqen-link_1.2.1_amd64.deb`.
Он рассчитан на Ubuntu 26.04 с процессором Intel/AMD x86-64.

Открой файл в приложении установки пакетов Ubuntu или выполни в каталоге с ним:

```bash
sudo apt update
sudo apt install ./veliqen-link_1.2.1_amd64.deb
```

APT загрузит системные зависимости из настроенных репозиториев. Для этого нужен
интернет и доступные репозитории Ubuntu, включая Universe. Самостоятельная
команда `dpkg -i` не загружает зависимости. Обычный DEB не является автономным
образом всех пакетов Ubuntu.

В DEB уже входят приложение, scrcpy 5.0.1 с ADB и сервером Android,
дополнение GNOME для буфера обмена, ярлык и запись автозапуска. Полный архив
и отдельный `INSTALL-UBUNTU.sh` для обычной установки не нужны.

## Первый запуск

Открой VELIQEN Link в меню приложений Ubuntu. На телефоне установи APK,
подключи оба устройства к одной сети Wi-Fi и подтверди сопряжение.

Разрешения SMS, звонков, показа экрана и управления выдаются на телефоне.
Звук звонков использует Bluetooth HFP. Нужны сопряжение Bluetooth и поддержка
профиля телефоном и ноутбуком. Настройка звука запускается кнопкой в приложении
и предупреждает о кратковременном перезапуске звуковой службы.

В настройках Ubuntu-приложения включи «Передавать буфер с Ubuntu на телефон».
Приложение включит только дополнение VELIQEN Clipboard. Если GNOME ещё не
обнаружил новое системное дополнение, выйди из сеанса Ubuntu и войди снова.
Ручная передача текста остаётся доступна кнопкой «Буфер».

Дополнение из старого полного комплекта переносится в резервную копию только
при точном совпадении двух файлов с официально поставленной версией.
Изменённая копия, дополнительные файлы и ссылки остаются без изменений.
В таком случае приложение попросит вручную сохранить пользовательскую копию
в резервной папке и войти в Ubuntu заново. Обычно эта копия находится в
`~/.local/share/gnome-shell/extensions/veliqen-clipboard@veliqen.tech`.
При заданном `XDG_DATA_HOME` каталог находится под ним.

Автозапуск при входе в Ubuntu включён по умолчанию. Его можно выключить
в настройках VELIQEN Link. Ранее созданное пользовательское отключение
автозапуска сохраняется при обновлении пакета.

## Состав установки

Системные зависимости включают Python/GTK, KDE Connect, BlueZ, PipeWire 1.4+,
WirePlumber 0.5+, инструменты маршрутизации звука, PolicyKit и библиотеки
отображения. Полный список находится в поле `Depends` пакета:

```bash
dpkg-deb --field ./veliqen-link_1.2.1_amd64.deb Depends
```

Установщик DEB не запускает вложенный APT, не перезапускает звук и не меняет
домашние каталоги пользователей от root. Он не обходит разрешения Android.

При обновлении закрой старое окно VELIQEN Link через «Настройки → Завершить»,
установи новый DEB и открой приложение снова. Сопряжения и настройки
пользователя сохраняются.

## Сборка и проверки

```bash
python3 BUILD-PACKAGES.py
/usr/bin/python3 -m unittest discover -s tests -p 'test_session_setup.py' -v
/usr/bin/python3 tests/check_standalone_deb.py
```

Сборщик проверяет SHA-256 официального архива scrcpy. Контрольная сумма
готового DEB записывается рядом с пакетом. Проверка жизненного цикла использует
отдельное пространство пользователя Linux и временный корень dpkg.
Она не устанавливает пакет в текущую систему. Зависимости внутри этого
синтетического корня намеренно не устанавливаются: это проверка распаковки,
обновления и удаления пакета, а не тест оборудования.
