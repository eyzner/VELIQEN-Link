# Установка VELIQEN Link 1.2.1

В полном комплекте открой папку **Установочные-файлы**. Для компьютера нужен `veliqen-link_1.2.1_amd64.deb`, для телефона — `VELIQEN-Link-1.2.1-Android.apk`. Эти же файлы можно скачать отдельно со страницы выпуска.

## 1. Установи приложение на Ubuntu

Поддерживаемая система — Ubuntu 26.04 на компьютере Intel или AMD 64-bit, с GNOME и PipeWire.

Открой терминал в папке с DEB и выполни:

```bash
sudo apt update
sudo apt install ./veliqen-link_1.2.1_amd64.deb
```

APT установит VELIQEN Link и скачает недостающие системные зависимости. Для этого нужны интернет и доступные репозитории Ubuntu.

Открой **VELIQEN Link** из меню приложений. После обновления закрой старое окно и открой приложение снова. Сопряжения и настройки Ubuntu сохраняются.

Для автоматической передачи буфера на GNOME Wayland включи **VELIQEN Clipboard** в настройках приложения. Если расширение ещё не появилось, выйди из сеанса Ubuntu и войди снова. Автозапуск можно отключить в настройках приложения.

### Если Ubuntu не может скачать зависимости

В распакованной папке полного комплекта выполни:

```bash
bash INSTALL-UBUNTU.sh --ubuntu-main-mirror
```

Запускай от обычного пользователя. Установщик сам запросит пароль `sudo`, скачает зависимости с официальных серверов Ubuntu и установит приложение. Изменять постоянные настройки репозиториев вручную не требуется.

## 2. Установи приложение на телефон

Передай `VELIQEN-Link-1.2.1-Android.apk` на телефон, открой файл и подтверди установку. Если Android попросит, разреши установку для приложения, через которое открыт APK.

Версия 1.2.1 устанавливается рядом с ранними тестовыми версиями. В новом приложении потребуется заново подтвердить сопряжение и выдать нужные разрешения. После перехода закрой или отключи прежнюю версию, чтобы не получать одинаковые уведомления от двух приложений. Её данные автоматически не переносятся.

Если VELIQEN Link уже встроен в прошивку и Android отклоняет установку APK, используй обновление, предназначенное для этой прошивки.

## 3. Подключи устройства

1. Подключи телефон и Ubuntu к одной сети Wi-Fi.
2. Открой VELIQEN Link на обоих устройствах.
3. Выбери найденный компьютер или телефон, проверь имя устройства и подтверди запрос сопряжения.
4. На телефоне открой **Доступы** и включи нужные функции.
5. Для звонков дополнительно подключи Bluetooth и разреши звук звонков.

Теперь можно передавать файлы и текст, открывать сообщения, звонки и экран телефона.

Android запрашивает подтверждение каждого нового показа экрана. Для управления мышью отдельно включи **Разрешить управление в этом сеансе** и запрошенный доступ **VELIQEN: управление экраном**. Приложение не может выдать себе эти разрешения автоматически.

Звук сотовых звонков передаётся по Bluetooth; файлы и экран телефона используют Wi-Fi. Работа звонков зависит от Bluetooth-адаптера и прошивки телефона.

## Удаление

На Ubuntu сначала заверши приложение в его настройках, затем выполни:

```bash
sudo apt remove veliqen-link
```

Настройки сопряжения хранятся у пользователя и автоматически не удаляются. Ранее установленная пользователем копия расширения GNOME может оставаться в домашней папке. Откат отдельно включённой настройки звонков описан в [инструкции по звонкам](CALLS_RU.md).

На телефоне удали VELIQEN Link через системные настройки приложений.
