# Проверка VELIQEN Link 1.2.1

Дата: 21 ноября 2026 года. Этот отчёт относится к публичной упаковке 1.2.1.

## Что проверено

| Область | Фактическая проверка |
| --- | --- |
| Пакет Ubuntu | Сборка amd64, состав, версии зависимостей, владельцы root:root, права доступа, соответствие исходникам |
| Жизненный цикл DEB | Реальная установка, обновление 1.2.0 all → 1.2.1 amd64, переустановка, удаление и purge во временном корне dpkg |
| Пользовательская настройка | 11 тестов GNOME/autostart и безопасной миграции старого расширения |
| Инструменты экрана | 8 тестов выбора ADB/scrcpy, авторизации и аргументов |
| Интерфейс Ubuntu | 12 настоящих GTK-рендеров с изолированными тестовыми службами, включая настройки автозапуска |
| Shell-установщик | Изолированный сценарий установки и сохранённое исправление локального APT |
| Android | Сборка 1.2.1, подписи v1/v2/v3, выравнивание 4 байта / 16 KiB, manifest, постоянный signer |
| ROM | Подстановка нового APK, dry-run, повторная установка, защита от конфликта, откат во временном дереве |
| Исходники Android | Полный патч применён к чистому upstream, 702 исходных файла совпали по SHA-256 |
| Публичные файлы | Проверка состава, исключение приватного ключа, ZIP CRC и манифесты SHA-256 |

Используемая среда сборки: Debian 13 x86_64. Проверка dpkg использует изолированные временные каталоги и пространство пользователя Linux. Зависимости в синтетическом корне намеренно отсутствуют и игнорируются только тестовой командой. Это проверка работы пакета, а не полная установка Ubuntu или её служб на оборудование пользователя.

## Android

- Application ID: `tech.veliqen.link`.
- Version code: `13706`.
- Version name: `1.37.3-veliqen-link-1.2.1`.
- JDK 21.0.13, Gradle 9.6.0, AGP 9.5.1, Kotlin 2.4.21.
- Compile/target SDK 37, min SDK 23, Build Tools 37.0.0.
- Постоянный сертификат: `2406bd4ece7d445fe73cea99c8dfc02b127a3c3689eeb723d7b6ef6733d69684` (SHA-256).
- `debuggable=false`, `testOnly=false`. Это обычный устанавливаемый APK, без требования `adb install -t`.
- FileProvider, AndroidX Startup и MMS provider используют новый ID.
- Приватные данные старого тестового приложения не переносятся и не удаляются автоматически.

Результат текущего фактического прогона в AOSP API 23 software emulator приведён в `android/EMULATOR-QA.json`, включая проверку установки рядом с прежним приложением. Он относится к указанной версии и условиям эмулятора, а не к Android 17 на физическом телефоне. Полные параметры сборки и подписи: `android/BUILD-STATUS.json`, `android/RELEASE-SIGNING.json`, текстовые записи в `android/build-output/`.

Точный журнал проверки пакета: `docs/qa/standalone-deb-1.2.1.txt`. Отдельные текущие журналы:

- `docs/qa/session-setup-1.2.1.txt`;

Системные зависимости объявлены в DEB. Минимумы PipeWire 1.4 и WirePlumber 0.5 подходят к опубликованным версиям Ubuntu 26.04. Включённый официальный scrcpy 5.0.1 и ADB 37.0.1 запущены с `--version`. Архив scrcpy, исходники его закреплённых библиотек и уведомления проверены по сохранённым SHA-256. Побайтовая воспроизводимость чужих бинарников не заявляется.

## Предыдущая проверка интерфейса

Выпуск 1.2.0 проходил 189 автоматизированных тестов без пропусков и более широкий сценарий интерфейса Android. Это историческая проверка, а не повторный прогон всех 189 тестов для версии 1.2.1. Её отчёт сохранён отдельно в `docs/VALIDATION-1.2.0.md`, соответствующие старые журналы имеют прежние имена. Номер версии внутри отчёта определяет его область применения.

## Что ещё требует проверки на целевых устройствах

Полная загрузка зависимостей APT на чистой Ubuntu 26.04, включение расширения в настоящем GNOME Shell, Bluetooth-сопряжение и двусторонняя слышимость сотового звонка на выбранном адаптере, DTMF с оператором, SMS и живое сопряжение с телефоном, Android 17 permission flows, MediaProjection/Accessibility на VELIQEN OS и полная сборка ROM здесь не подтверждены.

Скриншот пользователя демонстрирует его подключённый телефон и экран на Ubuntu в версии 1.1.0. Он не доказывает проверку всех функций нового пакета. Скриншоты `docs/screenshots` получены в указанной тестовой среде и используют демонстрационные данные.

## Материалы выпуска

Две презентации имеют по 9 слайдов, на русском и английском. Текст редактируется в PPTX. PDF получены через LibreOffice. Все страницы просмотрены, структура и геометрия PPTX проверены. В Microsoft PowerPoint презентации не открывались. Исходные скриншоты пользователя и демонстрационные данные подписаны, источники указаны в заметках.

GitHub workflow подготовлен и проверен как YAML, но в удалённом репозитории не запускался. Публикация на GitHub в ходе подготовки комплекта не выполнялась.
