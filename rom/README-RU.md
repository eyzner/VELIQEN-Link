# Подключение VELIQEN Link к VELIQEN OS

Этот набор **меняет исходники сборки ROM**, а не прошивает устройство. Нужен корень вашей AOSP/LineageOS-сборки и точный `.mk` выбранного продукта. Скрипт не угадывает продукт по названию телефона и не переписывает Settings, device tree или vendor HAL.

## Что добавляется

- Каталог `vendor/veliqen/link` с Android.bp, product.mk, разрешением DownloadManager и APK.
- Один отмеченный блок `inherit-product` в указанный вами product `.mk`.
- Локальная резервная копия изменяемого makefile и предыдущей версии каталога. Идентификатор транзакции выводится после установки.

Модуль называется `VELIQENLink`. Он устанавливается в `/product/priv-app` и подписывается **вашим существующим ключом `platform` при сборке прошивки**. Скрипт не меняет и не создаёт ключи ROM, не копирует чужой приватный ключ и не выдаёт отладочную подпись за производственную.

`READ_CLIPBOARD_IN_BACKGROUND` на Android 17 имеет уровень `signature|role`. Он добавлен в AndroidManifest приложения; его выдаёт правильная платформенная подпись. Его нельзя получить простым `pm grant` или записью в privapp allowlist. Сборка сама по себе не выдаёт SMS, контакты и уведомления без пользовательского выбора.

## Подключение

Перейдите в каталог `rom` этого комплекта. Сначала выполните проверку, указав **ваши реальные пути**:

```bash
bash INSTALL-ROM.sh \
  --tree /полный/путь/к/исходникам/LineageOS \
  --product-mk путь/внутри/дерева/к/вашему_product.mk \
  --dry-run
```

`--dry-run` не записывает ни исходники, ни резервные копии. Если проверка показывает верный продукт, повторите эту же команду без `--dry-run`.

По умолчанию APK берётся из `../android/artifacts`: сначала unsigned, затем release; если рядом нет Android-проекта, используется включённый `payload/prebuilt/VELIQENLink.apk`. Любой вариант повторно подписывается платформенным ключом ROM. Для своего APK задайте `--apk /полный/путь/к/VELIQEN-Link.apk`; установщик проверяет package ID `tech.veliqen.link`. Development APK с package `.development` или `.debug` не принимается.

После подключения выполните вашу обычную сборку. При уже настроенном окружении AOSP можно сначала проверить отдельный модуль:

```bash
m VELIQENLink
```

Сборка образа и установка образа на телефон выполняются отдельно вашим обычным способом. Отдельная сборка модуля не проверяет всю прошивку, Bluetooth-звук или совместимость GSI с устройством.

## Повторный запуск и откат

Повторная установка того же APK не меняет файлы и не дублирует подключение. Новая версия создаёт отдельную транзакцию. Если вы изменили файлы внутри установленного `vendor/veliqen/link`, установщик остановится, чтобы не потерять правки.

В выводе успешной установки есть идентификатор наподобие `20261120T120000Z-1234abcd`. Для просмотра отката подставьте реальный идентификатор:

```bash
bash ROLLBACK-ROM.sh \
  --tree /полный/путь/к/исходникам/LineageOS \
  --transaction ИДЕНТИФИКАТОР_ИЗ_ВЫВОДА \
  --dry-run
```

Затем повторите без `--dry-run`. Если product mk менялся после установки, откат удалит только свой неизменённый блок и сохранит остальные правки. Если изменён сам блок или файлы установленного модуля, автоматический откат остановится. Новые транзакции нужно отменять в обратном порядке. Резервные копии и снятый пакет остаются в `.veliqen-link-backups` дерева сборки.

## Проверка на телефоне после прошивки

Проверьте, что приложение запускается, и подтвердите сопряжение с Ubuntu. В авторизованном ADB проверьте фактически выданное `android.permission.READ_CLIPBOARD_IN_BACKGROUND` в разделе разрешений пакета:

```bash
adb shell dumpsys package tech.veliqen.link
```

Проверьте текстовый буфер в обе стороны при закрытом интерфейсе приложения. Контент, отмеченный Android как чувствительный, по умолчанию не отправляется автоматически. Отдельно проверьте SMS с выбранной SIM и выдачу уведомлений. Проверьте отключение доверия к компьютеру.

Если в продукте уже включён другой системный модуль KDE Connect, сначала определите, какую версию оставить: два APK с одним package ID включать нельзя. Установщик не удаляет чужой модуль автоматически.

Если ранее установлен публичный VELIQEN Link с тем же ID tech.veliqen.link и другим ключом, установка платформенной версии может конфликтовать. Этот установщик не удаляет приложения с телефона и не сбрасывает их данные.

## Подпись публичного выпуска и миграция

Публичный APK 1.2.1 использует `tech.veliqen.link` и отдельный постоянный ключ VELIQEN. ROM подписывает приложение своим platform-ключом, поэтому публичный APK не может обновлять встроенную сборку поверх неё. Обновляйте встроенное приложение вместе с прошивкой с сохранением platform-ключа. Прежняя тестовая сборка использовала `org.kde.kdeconnect_tp`; этот интегратор не удаляет её автоматически и не переносит её закрытые данные.
