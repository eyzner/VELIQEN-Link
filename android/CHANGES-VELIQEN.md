# VELIQEN Link: изменения Android-клиента

Основа — KDE Connect 1.37.3, commit `6b9e7b2cf371c5b40cf75079cc21e4e66b4b464d` из официального зеркала KDE. Полное авторство, SPDX-заголовки, COPYRIGHT/лицензии и список авторов сохранены. Это самостоятельная адаптация, а не официальный выпуск KDE.

## Версия 1.2.1

- Первый комплект с постоянной приватной подписью VELIQEN и собственным application ID `tech.veliqen.link`. Namespace исходников KDE сохранён. Приложение устанавливается рядом со старыми тестовыми версиями, без удаления их данных. Для перехода нужны новое сопряжение и разрешения.
- Исправлены зависимости от жёстко заданного ID в открытии принятых файлов, путях FileProvider, фильтрации собственных уведомлений и debug shortcuts. Сетевой протокол и имена Kotlin-классов сохранены.
- `versionCode` 13706, полное имя версии `1.37.3-veliqen-link-1.2.1`. Release APK не debuggable и не testOnly.
- Сборка по умолчанию требует уже существующий постоянный ключ. Первое создание вынесено в `INIT-SIGNING.sh`. Публичный сертификат и проверка APK входят в исходники, приватный ключ хранится отдельно.
- ROM-интеграция использует новый ID и unsigned APK для последующей platform-подписи.

## Версия 1.2.0

- Главный экран объединяет выбранный компьютер, состояние подключения и четыре основных действия: экран, файлы, буфер и звонки. Настройки и доступы открываются с этого экрана; системная кнопка «Назад» возвращает к предыдущему разделу.
- Настройки сгруппированы по назначению. Статус разрешений учитывает сеть и выбранные пользователем функции; отказ от необязательных уведомлений самого Link не выдаётся за отсутствие готовности основных функций.
- На широком экране, начиная с 600 dp доступной ширины, блок компьютера и основные действия располагаются рядом. Общая ширина содержимого ограничена, чтобы элементы не растягивались по всему планшету или горизонтальному экрану.
- Сохранены существующие сопряжения, способы передачи, MediaProjection и отдельное разрешение управления. Экран и файлы продолжают использовать Wi-Fi, настройка сотовых звонков ведёт к Bluetooth.
- Package ID и публичная development-подпись сохранены. `versionCode` увеличен до 13705; полное имя версии — `1.37.3-veliqen-link-1.2.0`.

## Версия 1.1.0

- Новый главный экран `VeliqenHomeActivity`: состояние связи, выбор компьютера, основные действия и понятные доступы по функциям. Сложные модули оставлены в дополнительном меню.
- Входящие запросы сопряжения можно принять или отклонить через отдельное действие; старые переходы в приложение ведут на новый главный экран.
- Новый значок VELIQEN для варианта сборки: adaptive icon, monochrome и вариант для старых Android.
- Нативный показ экрана через MediaProjection без ADB. Сеанс запускается только после видимого действия пользователя и штатного системного согласия.
- Новый локальный протокол изображения и ограниченного ввода на TCP 38475. Взаимная TLS-аутентификация использует сертификаты уже сопряжённых устройств KDE Connect. Адрес берётся из текущего подтверждённого LAN-соединения.
- Отдельная Accessibility-служба для управления экраном: команды принимаются только в активном сеансе с разрешённым управлением. Блокировка телефона, прекращение доверия и потеря соединения останавливают показ. Поля пароля исключены из вставки текста.
- Запрос с Ubuntu передаётся через типизированное сообщение Ping от сопряжённого устройства и создаёт уведомление. Он не запускает захват автоматически.
- Ограничены частота и размер изображения, длина команд и очереди кадров/ввода. Поворот экрана на Android 14+ обрабатывается изменением существующей поверхности без повторного использования токена захвата.
- Сохранены package ID и development-подпись версии 1.0; versionCode увеличен до 13704. Данные приложения не очищаются.

## Сохранённые изменения версии 1.0

- Название приложения во всех переводах: VELIQEN Link. Package ID сохранён: `org.kde.kdeconnect_tp`.
- В разделе «О приложении» добавлено указание на адаптацию и доступность изменённых исходников; ссылка на исходники явно обозначает KDE. Обращения об ошибках адаптации не отправляются автоматически в KDE.
- Добавлен вариант сборки `veliqen`, без смены package ID. Личная подпись принимается через переменные среды; по умолчанию вариант не подписан.
- `READ_CLIPBOARD_IN_BACKGROUND` запрашивается для платформенной подписи VELIQEN OS. Автоматический режим определяется проверкой реально выданного разрешения.
- Удалено использование чтения logcat для обхода фонового буфера. Обычный APK поддерживает ручную отправку буфера. Автоматический фоновый режим требует системной интеграции и соответствующей подписи.
- Контент, помеченный Android как чувствительный, по умолчанию исключён из автоматической передачи. Ручная отправка остаётся осознанным действием пользователя. Это не гарантированное распознавание всех паролей и OTP.
- Основное сопряжение, SMS, контакты, уведомления и передача файлов используют оригинальную реализацию KDE Connect. Нативный экран версии 1.1 использует отдельный локальный канал с теми же доверенными сертификатами.

Сборка APK сама по себе не проверяет работу на конкретном телефоне. Звонки с двусторонним звуком обеспечивает Ubuntu-часть через Bluetooth HFP; Android-форк не добавляет передачу телефонного звука через Wi-Fi. Результаты выполненных проверок находятся в `BUILD-STATUS.json` и `../docs/VALIDATION.md`.
