# VELIQEN Link для Android / VELIQEN OS

Подключи телефон к Ubuntu, чтобы передавать файлы и текст, работать с SMS, звонками и экраном телефона на компьютере.

## Установка

Открой `VELIQEN-Link-1.2.1-Android.apk` на телефоне и подтверди установку. В полном комплекте файл находится в папке **Установочные-файлы**. Если Android попросит, разреши установку для файлового менеджера или браузера, через который открыт APK.

Приложение не требует Google Play Services. Для обычной установки режим разработчика и USB-отладка не нужны.

### Переход с тестовых версий 1.0–1.2.0

Версия 1.2.1 устанавливается как отдельное приложение. Настройки и данные остаются в прежней версии. В новой один раз подтверди сопряжение с Ubuntu и выдай нужные разрешения. После перехода закрой или отключи старую версию, чтобы оба приложения не создавали одинаковые уведомления и подключения.

Если приложение уже встроено в VELIQEN OS и Android отклоняет установку APK, используй обновление, предназначенное для этой прошивки.

## Подключение

1. Подключи телефон и компьютер к одной сети Wi-Fi.
2. Открой VELIQEN Link на обоих устройствах.
3. Разреши доступ к локальной сети, если Android его запросит.
4. Выбери найденный компьютер, проверь имя устройства и подтверди сопряжение.
5. Открой **Доступы** и включи нужные возможности: SMS, контакты, уведомления и управление экраном.

Для сотовых звонков дополнительно подключи телефон к Ubuntu по Bluetooth и разреши звук звонков. Файлы и экран телефона используют Wi-Fi.

## Главный экран

Вверху находятся выбранный компьютер и состояние связи. Ниже — четыре действия:

| Действие | Что можно сделать |
| --- | --- |
| Экран | Показать экран телефона на Ubuntu |
| Файлы | Выбрать файл и отправить на компьютер |
| Буфер | Передать скопированный текст |
| Звонки | Открыть подключение звонков через Bluetooth |

Настройки открываются кнопкой в верхней панели, доступы — отдельной строкой. Кнопка «Назад» возвращает на предыдущую страницу. В горизонтальной ориентации и на планшете блоки располагаются рядом, когда хватает места.

Уведомления самого Link помогают видеть входящие запросы. Остальные возможности включаются отдельно. Дополнительные параметры доступны через **Настройки → Настройки возможностей**.

## Экран телефона на Ubuntu

Нажми **Экран** с подписью **Показать на Ubuntu** на телефоне. Также можно отправить запрос с компьютера и открыть уведомление Link на телефоне. Подтверди системный запрос Android — изображение откроется на Ubuntu.

Для управления мышью перед запуском отметь **Разрешить управление в этом сеансе** и включи отдельный доступ **VELIQEN: управление экраном** в специальных возможностях. Для просмотра этот доступ не требуется.

Android запрашивает согласие на каждый новый сеанс. При блокировке телефона, завершении показа или потере соединения сеанс прекращается. Пароль и PIN сохраняют защиту телефона; защищённые экраны могут скрываться системой. Текст в поле пароля через удалённый ввод не записывается.

Управление доступно только подтверждённому сопряжённому компьютеру. Кадры не записываются в файл. Используй Ubuntu-часть из этого же комплекта 1.2.1.

Обычный показ экрана не требует режима разработчика, ADB, IP-адреса или кода отладки. Звук видео в этом режиме не передаётся. Для сотовых звонков используется Bluetooth.

Подробнее: [экран телефона](../docs/NATIVE_SCREEN_RU.md).

## Буфер обмена

Android ограничивает чтение буфера в фоне. В обычном приложении пользуйся кнопкой **Буфер** для отправки текста. Автоматическая передача из фона требует системной интеграции в VELIQEN OS. Остальные доступы включай по необходимости.

## О проекте

VELIQEN Link основан на KDE Connect 1.37.3. Исходники и лицензии включены в комплект. Сведения о происхождении и изменениях находятся в `UPSTREAM.json` и `CHANGES-VELIQEN.md`, лицензии — в `kdeconnect-android/COPYING` и `kdeconnect-android/LICENSES/`.
